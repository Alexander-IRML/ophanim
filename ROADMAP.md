# OPHANIM roadmap

## Current work: hypothesis → imagined 3D event → ShawtyNet

Keep three boundaries: core acquisition/measurement science; experiments and
simulation; downstream ShawtyNet art. An imagined 3D field is not a recovered
electron-density distribution, and its parameters never enter scientific evidence.
Preserve source links, alternative hypotheses, chosen parameters and random seeds.

## v0.3 — IFM (explicitly deferred)

**User commitment: revisit IFM for v0.3. Do not omit this from v0.3 planning.**

- [ ] Recheck IFM availability, access, licensing and supported execution routes.
- [ ] Define forcing/background inputs and a versioned 3D model-output adapter.
- [ ] Distinguish model-derived priors from TEC observations and artistic choices.
- [ ] Benchmark against the local imaginative model before claiming improvement.
- [ ] Complete the remote-backend security review before enabling any service.

IFM is not installed, integrated or being run by the current imagination workflow.
The local model is intentionally a procedural, evolving artistic approximation.

## Remote execution: permitted direction, not an enabled service

Select a provider and explicitly authorize its data, credentials and cost scope
before implementation. See [simulation security](docs/simulation-security.md).
Local simulation, preview, rendering and exports must remain usable independently.
