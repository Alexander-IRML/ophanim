# Changelog

All notable changes to OPHANIM are recorded here. The project follows
[Semantic Versioning](https://semver.org/).

## [0.2.0] - 2026-09-19

Evidence-linked discovery, experiments, and ShawtyNet:

- separate reusable core acquisition/modeling, experimental simulation, and
  downstream artistic rendering behind tested subsystem boundaries;
- focused Discover → Event Lab → Studio workspace, saved hotspot evidence,
  reproducible recipes, durable jobs, cancellation, and immutable result history;
- native-grid hotspot discovery with explicitly tentative explanations and
  optional timestamp-matched geomagnetic context;
- source-aware dynamics, per-frame state/event contracts, wave and apparent-flow
  analysis, scientific diagnostics, and stricter sampling/uncertainty checks;
- evolving imagined 3D volumes with hypothesis provenance, seeded advection,
  diffusion, and forcing; wave ribbons, front curtains, and jet bundles;
- artistic volume previews, Blender stills and animations, portable validated
  scene exports, and manually aligned photo compositing with masks;
- safeguards for local authenticated workflows, bounded computation, trusted
  renderers, and malformed or oversized exported-scene data;
- Chrome workflow checks, numerical regressions, and reproducible real-render
  acceptance scripts; existing 2D research tools remain available.

Imagined geometry is not a recovered plasma distribution or a confirmed event
diagnosis. Remote simulation remains disabled, and IFM is explicitly deferred
to v0.3. Existing source datasets and saved artifacts remain unchanged.

## [0.1.0] - 2026-09-16

First experimental deployment:

- dependency-free local TEC ingestion, regional aggregation, forecasting, and
  disturbance-candidate workflow;
- automatic CODE GIM acquisition and fine regional readout tables;
- PostgreSQL catalog plus immutable native and derived Zarr storage;
- resumable twenty-year selective state-space (Mamba-style) baseline;
- causal native-grid ConvLSTM baseline with side-by-side anomaly comparison;
- loopback-only desktop application that prefers Windows Google Chrome, plus a
  Docker Compose deployment.

This release is a research experiment, not an operational space-weather alert
service.
