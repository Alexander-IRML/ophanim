# ShawtyNet V1 implementation record

## Repository fit

OPHANIM v0.1 uses frozen dataclasses, Protocol interfaces, argparse, unittest,
SQLite application state, an optional PostgreSQL catalog and verified immutable
Zarr TEC grids. Acquisition and IONEX parsing already exist. Native GIM spacing
is 5 degrees longitude by 2.5 degrees latitude; the 0.5-degree representation is
derived interpolation. Monitoring models have their own cadence and must not
be prerequisites for observational analysis. The core package stays usable
without optional scientific or rendering dependencies.

## Ownership and amended requirements

* `ophanim.core`: model-independent acquisition/catalog access, native discovery
  and map contracts, reusable model interfaces, scientific artifact publication,
  and the shared local compute gate. No experiment or art dependencies.
* `ophanim.sensing`: read-only observation snapshots over existing sources;
  native source support, available-at selection, optional IONEX RMS preservation.
* `ophanim.dynamics`: reusable scientific calculations and source capability gates.
* `ophanim.experiments`: independent hypothetical scenarios, synthetic truth,
  degradation tests and model/agent evaluation extension contracts. No art imports.
* `ophanim.shawtynet`: deterministic art mapping, curved geometry, Blender export
  and manual photographic compositing; its own visual/render/composite run stages.
  Never modifies scientific products or imports experimental generators.
* `ophanim.workspace` / `ophanim.shawtynet_cli`: application composition and user
  handoffs between the independent subsystems. `ophanim.science_runs` preserves
  the previous stage APIs through a lazy compatibility facade.

These are explicit boundaries inside a modular local application, not a
microservice migration. [Subsystem contracts](subsystems.md) document allowed
dependencies and the distinction between real capabilities and extension seams.

Source spacing and effective resolution are distinct. Unknown effective
resolution and source uncertainty remain unknown. Interpolation cannot improve
admitted physical wavelength or period bands. Six actual source samples per
period and three observed cycles are configurable conservative engineering gates,
not a claim of guaranteed physical resolution. Directional spatial sampling and
the analysis extent also constrain wave eligibility.

Internal coordinates use metres and seconds. Apparent TEC-feature motion is not
plasma velocity. Growth and transport may be observationally ambiguous. Signed
FFT frequencies determine propagation; conjugate peaks represent the same wave.
Phase includes its spatial and temporal origin. Missing support propagates through
operators; unavailable channels are not quiet zero-valued observations.

Retrospective analysis is the art default. Causal analysis excludes later samples
and later-available revisions, including during normalization/preprocessing.
Coverage, source RMS, observability and fit are separate quantities. Heuristic
confidence/event scores are not calibrated probabilities.

Science is immutable and separately identified from each art recipe. Visual
altitude, opacity floor, colors, fibers and vertical exaggeration are explicitly
artistic. A new style must not rerun or modify scientific inference.

## Discovery-led workspace

The main interface now follows **Discover → Event Lab → ShawtyNet Studio**.
The previous long-form operator dashboard remains under **Advanced**, and the
independent **Experiments** surface identifies unconfigured future research
capabilities explicitly.

- One primary action requests a bounded recent CODE window, reuses retained
  native source data, and performs native-grid triage. It does not initialize
  Mamba/ConvLSTM or require the optional PostgreSQL deployment.
- Discovery compares supported native cells with prior days at the same UTC,
  joins adjacent cells, tracks persistence across epochs, and returns at most
  three distinct candidates. No supported candidate and insufficient-history
  results are legitimate outcomes, not failures to fill a card quota.
- Event evidence includes source times/cadence/spacing, native footprint,
  baseline-relative deviation, time series, support and alternative explanations.
  Descriptive explanations are not confirmed physical causes. Optional NOAA
  planetary Kp context is attached only for overlapping three-hour UTC intervals;
  it does not change candidate detection/ranking or establish a local cause.
  Missing/out-of-window context remains unavailable, never inferred calm.
- A selected candidate can seed an explicitly hypothetical scenario, or its
  native evidence can be analyzed and artistically mapped without synthesizing
  a replacement observation. Recipes retain candidate/snapshot lineage and
  label inherited estimates versus chosen shape, motion, scale and timing.
- Scientific runs are published in the reusable core; artistic runs remain
  downstream and separately identified. Restyling reuses the immutable science.
  Scene/recipe exports preserve the reproducible handoff.
- Studio supports bounded 3–12-frame animations, recording selected scientific
  epochs separately from the uniform artistic GIF playback speed. Preview frames
  use 640×426 output, eight samples and two Blender threads; cancellation is
  checked between frames and partial animations are not published as complete.
- Local single-frame PNG/JPEG photo uploads are limited to 8 MiB/12 megapixels;
  EXIF orientation is applied and metadata removed. The convenience composite
  center-crops the photo, blends an existing rendered frame, and records its
  chosen horizon/opacity. It does not infer camera alignment or foreground masks.
  The original CLI/API mask-aware compositing workflow remains available.
- Workspace jobs/results survive restarts. Cancel requests take effect at safe
  stage boundaries; interrupted requests can be retried with completed stages
  reused. A shared per-data-directory gate serializes heavy scientific/model
  work, while scenario allocation is bounded to 200,000 space-time cells.
- The recent-source catalog is independent of model training, with indexed
  time-window reads and retained original bytes. Existing forecast and historical
  model stores are preserved; this is not a migration of every legacy ledger.

Independent experiment contracts require immutable artifact references,
chronological train/validation/test intervals, distinct partition references and
content hashes, seeds and explicit metrics. Dependency-direction and base-import
tests enforce the separation. Agent environment/trainer protocols and novel-model
adapter seams are present, but **no agent trainer, learning environment, new
research model or general benchmark runner is configured**.
