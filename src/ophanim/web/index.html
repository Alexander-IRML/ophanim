CODE Global Ionosphere Map

A global VTEC grid produced by the Center for Orbit Determination in Europe and downloaded directly by OPHANIM. Each typically two-hour snapshot has one TEC value per 5° × 2.5° cell.

Single-center GIM · not IGS combined
